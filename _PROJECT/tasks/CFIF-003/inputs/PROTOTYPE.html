Delivery boundary

  • Local chat history, request lifecycle, reports and profile are interactive, not server-backed.
  • Sign-out clears drafts and pending work. Completed chats remain in memory until reload or Reset demo.
  • Account separation is an interface simulation, not a security boundary. All fictional fixtures are inspectable in this file.
  • Reports are read-only snapshots: no editing, filtering, sorting, charting or exporting.
  • The supplied logo is embedded. System fonts and newly authored functional icons need no external assets.
